# Products New - Stage 011 Dashboard & KPI Centre

This parcel adds the Products New management dashboard and KPI centre while keeping the legacy Product module untouched.

## Added
- KPI Dashboard service
- KPI Centre controller
- Dashboard snapshots
- KPI preference entity
- Enhanced dashboard view
- KPI centre page
- Immediate attention low stock panel
- Recent product activity panel
- Stage SQL and updated master SQL

## Notes
- SQL is global tenant-safe and does not include any database name.
- Stock quantities are displayed with 3 decimals.
- This stage reads existing ERP product/variation/location tables and Products New standalone extension tables.
