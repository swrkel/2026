# Products New - Stage 005

Adds standalone Barcode Center, Label Template Center, and Product Media Center.

## Includes
- Barcode queue enhancement with template and barcode value support
- Barcode / QR label template management
- Product media registry for images, manuals, certificates, videos, and external links
- Product primary image support through standalone products_new_media table
- New services and controllers under ProductsNew only
- Parcel SQL and updated master SQL

## Notes
- Current old Product module remains untouched.
- No hardcoded database name is used.
- Tables are business-scoped for multi-business tenants.
