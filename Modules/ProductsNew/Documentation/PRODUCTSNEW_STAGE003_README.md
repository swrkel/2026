# Products New - Stage 003 Product Master

This parcel adds the visible standalone Product Master layer for the temporary `Products New` module.

## Included
- Product Master list with filters
- Add Product page
- Edit Product page
- Product 360° View
- Dropdown lookups for category, sub category, brand, unit, warranty, and tax
- Duplicate SKU guard per business
- Health score display
- Timeline logging on create/update
- POS-style product master UI improvements
- Parcel SQL and updated master SQL

## Important
The old Product module is untouched. Products New currently reads/writes the existing product master tables safely while storing Products New-only metadata in `products_new_*` tables.
