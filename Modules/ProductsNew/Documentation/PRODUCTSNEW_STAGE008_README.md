# PRODUCTSNEW Stage 008 - Serial, Warranty and Ownership Centre

This parcel adds serialized inventory controls to the standalone Products New module.

## Included
- Serial Number Centre
- Serial 360° view
- Serial movement history
- Warranty Registration Centre
- Warranty Claim handling
- Ownership History page
- Standalone entities, services, controllers and views
- Parcel SQL and updated master SQL

## Notes
- Existing Product module remains untouched.
- All tables use `products_new_` prefix.
- SQL has no hardcoded database name and can be executed per tenant database.
