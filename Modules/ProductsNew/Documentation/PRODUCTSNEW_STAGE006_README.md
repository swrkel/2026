# PRODUCTSNEW_006 - Product Intelligence Centre

This stage adds the first intelligence layer for Products New while keeping the legacy Product module untouched.

## Included
- Product Intelligence dashboard
- Product health summary page extension
- Product relationship centre
- Product lifecycle workflow/status transition centre
- Smart duplicate detection and review queue
- Product notes/internal knowledge centre
- Branch availability matrix
- Standalone entities, services, controllers, views and routes
- Parcel SQL and updated master SQL

## URLs
- `/products-new/intelligence`
- `/products-new/intelligence/relationships`
- `/products-new/intelligence/workflow`
- `/products-new/intelligence/duplicates`
- `/products-new/intelligence/notes`
- `/products-new/intelligence/availability`

## SQL
Run `ProductsNew_STAGE006_PRODUCTSNEW_006_INTELLIGENCE_CENTRE.sql` in every tenant database that should use Products New.
