# BKG-MFI-002 Banking Microfinance Operations Extension

Standalone add-on parcel for `Modules/BankingMicrofinance`.

Adds loan guarantors, rescheduling workflow, penalty rules/charges, group meetings/attendance shell, aging report, portfolio report and collection efficiency report.

Install by copying this module over BKG-MFI-001, loading `Routes/web_bkg_mfi_002.php` from the module provider/route loader, then running migrations after backup.

Safety: no Contacts, Customers, Finance, Petro, PetroPD, Leasing, Pawning or Insurance files are modified.
