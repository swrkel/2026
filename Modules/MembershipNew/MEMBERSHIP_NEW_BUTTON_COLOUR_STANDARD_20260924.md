# Membership New - System Standard Button Colours - 24 Sep 2026

Button colours are now assigned by action meaning throughout Membership New:
- Primary blue: Add, Search, Apply, queue/request actions.
- Success green: Save, Approve, Pay, Complete/Sync actions.
- Warning amber: Redeem, Replace, duplicate scans and caution actions.
- Danger red: Reject, Block, Reverse and destructive actions.
- Info cyan: Lookup, Print, Process and information actions.
- Purple: Dividends, column visibility and advanced report actions.
- Light/white: Reset, Cancel and neutral navigation actions.

The shared module CSS also maps standard `.btn-primary`, `.btn-success`, `.btn-warning`, `.btn-danger`, `.btn-info`, and `.btn-default` classes to the same Membership New design standard.
