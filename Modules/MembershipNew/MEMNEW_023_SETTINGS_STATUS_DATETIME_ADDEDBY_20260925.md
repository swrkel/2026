# MEMNEW_023 – Settings Status, Date & Time, Added By

Changes:
- Membership Settings moved to the last Membership-New sidebar position.
- Membership New list/report date fields now display date and time where the row has a creation time.
- Operational list/report tables show Added By using the real user name when a creator is known.
- Regions: first Action column, Edit, Change Status, Date & Time, Added By, Enabled/Disabled status (default Enabled).
- Membership Types: first Action column, Edit, Change Status, Date & Time, Added By, Enabled/Disabled status (default Enabled).
- Non-destructive schema migration adds status and creator tracking columns where missing.
