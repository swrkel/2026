# Auto Service Stage 008 - Consolidated Finance + Portal Package

This package consolidates Stage 004/005 invoice-payment-delivery work with Stage 006 workshop operations and Stage 007 customer vehicle status portal, so no completed functionality is lost when replacing files.

Included:
- Invoices and invoice print
- Payments and balance tracking
- Vehicle delivery action
- Workshop operations
- Mechanic assignment
- Parts reservation/issue/return
- Customer vehicle status portal
- Search by current job number, vehicle number, or mobile number
