# Leads-New Production Readiness Checklist

- Sidebar visible only when module is enabled and permitted.
- Dashboard loads without JavaScript or Laravel errors.
- Lead Add/Edit/View/Delete works.
- Follow-up, note, task, call, meeting, document pages work.
- Reports load and export.
- Settings save independently per business/tenant.
- Multi-tenant isolation verified.
- Multi-branch filtering verified.
- Permissions verified with restricted users.
- Existing Leads module verified unaffected.
