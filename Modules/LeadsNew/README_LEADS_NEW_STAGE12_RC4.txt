Leads-New Stage 12 RC4
======================
Large consolidated parcel for the standalone Leads-New module.

Adds:
- Workflow engine controllers/services and stage transition rules.
- Customer 360 view shell.
- Advanced saved-search screens.
- Bulk operation workflow hardening.
- Notification center and digest framework.
- Document category/folder/version support.
- Administration pages for number series, working days, templates, and permissions.
- API integration framework and webhook service.
- Final standalone dependency audit service and deployment checklist.

Scope:
All files are inside Modules/LeadsNew only. No existing Leads module files are modified.
Shared usage is limited to Laravel/auth/tenant/permission framework services needed for the ERP.
