# Leads-New Server Testing Script

## 1. Super Admin
- Open All Businesses / Manage.
- Enable Leads-New for one test business only.
- Save.
- Confirm other businesses do not show Leads-New.

## 2. Permissions
- Assign View, Create, Edit, Delete, Reports, Dashboard, Settings.
- Login as test user.
- Confirm menu visibility and route access.

## 3. Lead Workflow
- Add a lead.
- Edit the lead.
- Add a note.
- Add a follow-up.
- Upload a document.
- Convert to opportunity.
- Mark as won/lost.

## 4. Reports
- Open each report.
- Apply date range.
- Export Excel, CSV, PDF.
- Print.

## 5. Logs
- Review `storage/logs/laravel.log` for errors.
