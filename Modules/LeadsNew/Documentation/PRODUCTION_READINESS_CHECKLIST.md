# Production Readiness Checklist

- [ ] Sidebar is hidden when the module is disabled.
- [ ] Sidebar is visible when enabled for the business.
- [ ] Routes are protected by permission middleware.
- [ ] Dashboard opens without JavaScript errors.
- [ ] Add Lead saves correctly.
- [ ] Edit Lead updates correctly.
- [ ] View Lead opens correctly.
- [ ] Delete/Archive respects permissions.
- [ ] Follow-ups save and show in timeline.
- [ ] Notes save and show in timeline.
- [ ] Documents upload/download correctly.
- [ ] Reports filter by date, branch, user, and status.
- [ ] Excel/CSV/PDF/Print exports work.
- [ ] Business A cannot see Business B data.
- [ ] Branch restrictions are respected.
- [ ] Audit log records create/update/delete actions.
