Simple Audit v1.0.17 - Purchase Audit submenu fix

Purpose
-------
The Central sidebar was showing only the parent module name "Simple Audit".
This release keeps the dedicated host sidebar-section file and restores a
visible child page underneath it:

Simple Audit

The submenu is expanded by default on Central Super Admin pages so the child
page is immediately visible. It can still be collapsed by clicking the parent.

No database changes.
