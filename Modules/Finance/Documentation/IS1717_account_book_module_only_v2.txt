IS1717 Finance Account Book - Module-only correction v2

Cause corrected
---------------
The Account Book action was still generating the legacy URL:
/accounting-module/account/{id}

That URL was handled by the root AccountController and rendered:
resources/views/account/show.blade.php

The rendered root view then requested the missing route finance.account.book-data,
causing the HTTP 500 RouteNotFoundException.

Module-only correction
----------------------
1. FinanceServiceProvider now loads Finance routes from Modules/Finance/Routes/web.php.
2. Account Book uses unique Finance-owned URLs under:
   /accounting-module/account-book/{id}
3. List Accounts action links are generated by the Finance AccountController.
4. The legacy StandaloneAccountController is now only a bridge to the Finance
   module AccountController and no longer extends the root controller.
5. Individual and main Account Book views use Finance-owned data and balance routes.
6. No app/, resources/, routes/, config/, or other root file is included or changed.

No SQL or migration is required.
