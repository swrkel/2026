# BKG-CORE-006 Mobile Banking Enterprise Edition

Standalone module for Banking Suite mobile banking UI/API readiness.

## Upload
Copy `project_root/` contents to Laravel root.

## Main URL
`/banking/mobile-banking`

## Includes
- Mobile customer registration shell
- Device binding / device sessions
- Mobile transfer requests
- QR payment shell
- Bill payment shell
- Push notification preferences
- Wallet/linkage readiness
- Reports and settings pages

All files are under `Modules/BankingMobileBanking/` except the optional BankingUI menu fragment.
