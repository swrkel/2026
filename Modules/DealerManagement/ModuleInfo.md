# Dealer Management Module

**Module:** Dealer Management  
**Alias:** dealer-management  
**DB Prefix:** dlr_  
**Architecture:** Standalone dealer portal and dealer inventory subsystem.  
**Distribution dependency:** Business eligibility only; integration isolated through adapter/database event boundary.  

### Included
Dealer setup, default outlet, dealer admin creation, 4-digit login codes, password change/reset, staff users, outlet restriction, roles/permissions, dealer dashboard buttons, dealer stock ledger, physical stock confirmation, stock history, re-order rules, suggested quantities, Dealer Notification Centre, order requests, delivery/return visibility, reports summary, audit logs, and idempotent Distribution New delivery/return stock sync.

## 25 Sep 2026 - System Standard POS Design Update
All Dealer Management distributor and dealer-facing screens were aligned to the ERP System Standard / POS Dashboard visual baseline. Shared toolbars, numeric formatting, date range filtering, dropdown search, notes, responsive cards and list/report styling are included.
