# S782 Communication Hub fix - 27 Sep 2026

Issues addressed:

1. SMS Packages no longer depends on a manual pre-created `communication_hub_sms_packages` table. The module now safely creates/repairs this module-owned table in the active tenant database before loading or saving the page.
2. Settings no longer disables Save Settings when `communication_hub_settings` is missing. The module safely creates/repairs the table and keeps Save Settings enabled.
3. Settings are now saved with the current `business_id` + setting key so one business does not overwrite another business's settings in the same tenant database.
4. Existing data is preserved. The schema guard only creates missing tables/columns and never drops tables or rows.
5. If the tenant DB user does not have CREATE/ALTER permission, the page remains usable and shows a clear message; the real exception is also written to the Laravel log.

Deployment:
- Replace the CommunicationHub module with this parcel.
- Run `php artisan optimize:clear`.
- Open Communication Hub > SMS Packages and save a package.
- Open Communication Hub > Settings, change a value and click Save Settings.
