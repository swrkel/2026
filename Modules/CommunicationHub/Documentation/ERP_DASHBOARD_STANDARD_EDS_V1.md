# ERP Dashboard Standard (EDS v1.0)

Communication Hub is the first reference module for the ERP dashboard standard.

## Dashboard layout

1. Professional hero header with module title, description and quick actions.
2. KPI section uses 4 columns on desktop with two KPI rows where eight KPIs are available.
3. KPI cards have clear icon, number, description, colour accent, hover state and compact spark line.
4. Analytics section follows the KPI section.
5. Recent activity / operational panels use consistent card spacing and table layout.
6. Quick actions appear in one clean bottom action strip.

## Responsive rules

- Desktop / large laptop: 4 columns.
- Medium screens: 2 columns.
- Mobile: 1 column.

## Communication Hub applied pages

- `/communication-hub`
- `/communication-hub/commercial/sms-dashboard`

This standard should be reused for future dashboards such as Banking, Insurance, Hotel, MyHealth, Customers, Petro, Petro PD, Membership and Distribution.

## Deployment note

This package changes only Communication Hub presentation files and documentation. No database schema change is required for this UI standard update.
