# COMMUNICATIONHUB_006 - Enterprise Communication Centre

This phase adds a professional operational control centre for all communication channels while keeping CommunicationHub standalone.

## Included

- Enterprise dashboard
- Provider monitor
- Queue monitor
- Template designer overview
- OTP Centre overview
- Campaign Manager foundation
- Communication audit readiness page

## Standalone Rules

- No dependency on legacy SMS module.
- No dependency on legacy Wallet module.
- No dependency on My Health or any other business module.
- CommunicationHub owns its routes, controllers, services, views, entities and migrations.
