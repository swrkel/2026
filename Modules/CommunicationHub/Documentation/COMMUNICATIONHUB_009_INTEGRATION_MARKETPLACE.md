# COMMUNICATIONHUB_009 - Integration Marketplace

This release adds a standalone provider marketplace inside CommunicationHub.

## Scope

- Provider package catalogue
- Install / enable / disable workflow
- Sandbox test foundation
- Provider version and compatibility tracking
- Cost per provider/channel foundation
- Marketplace dashboard and reports foundation

## Standalone Rules

CommunicationHub marketplace does not depend on:

- Legacy SMS module
- Legacy Wallet module
- My Health
- Finance
- CRM
- Petro PD
- Any business module

It uses only CommunicationHub tables, controllers, services, routes, views and configuration.
