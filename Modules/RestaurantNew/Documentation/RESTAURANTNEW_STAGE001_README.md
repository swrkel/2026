# RestaurantNew Stage 001

This package creates the standalone Restaurant-New foundation.

## Included
- Module bootstrap, config, providers, routes, middleware shell.
- Standalone views, assets, language file, permissions file.
- Initial tenant/business scoped models and utility.
- Initial migration and separated SQL files.

## Important
- This module is intentionally independent and keeps Restaurant-New business logic inside `Modules/RestaurantNew`.
- Stage 001 does not modify existing working modules.
- Next stage should add restaurant settings, dining areas, table status workflow, kitchen sections and numbering settings.
