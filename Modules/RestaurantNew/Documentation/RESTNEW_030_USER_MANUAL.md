# RestaurantNew User Manual

## Waiter/Cashier
- Open Restaurant POS.
- Select order type: dine-in, takeaway, or delivery.
- Select table/customer where applicable.
- Add menu items, variants, modifiers, discounts, and notes.
- Save order and send to kitchen.
- Print bill or finalize payment when customer is ready.

## Kitchen
- Open Kitchen Display.
- View all received orders.
- Print or reprint KOT/bill copy if permitted.
- Change item/order status from received to preparing, ready, and served/collected.

## Manager
- Use command center dashboards for live sales, active tables, kitchen load, pending bills, delivery, staff performance, and reports.

## Super Admin
- Enable/disable RestaurantNew features per business/location.
- Assign permissions and review audit logs.
