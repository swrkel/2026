# RestaurantNew Stage 016 - Procurement and Production

Adds standalone restaurant procurement and production foundations:

- Supplier quotations
- Purchase orders
- Goods receipts / GRN
- Production batches
- Central kitchen / commissary transfers
- Procurement and production permissions
- Separate CREATE / ALTER / INSERT SQL files

All files are contained inside `Modules/RestaurantNew` and keep RestaurantNew independent.
