# RESTNEW 024 - Enterprise Kitchen Display System

Adds touch-friendly enterprise KDS capabilities inside RestaurantNew.

## Included
- KDS screen setup
- Live kitchen queue
- Kitchen section routing
- Priority ordering
- Preparation timers
- Overdue/warning indicators
- Status logs
- Kitchen notifications
- Chef assignment foundation
- AJAX status updates
- SQL create and permission scripts

## Main route
`/restaurant-new/kds-enterprise`

## Notes
This stage is standalone and uses only RestaurantNew namespace, routes, services, views, assets, migrations, and SQL files.
