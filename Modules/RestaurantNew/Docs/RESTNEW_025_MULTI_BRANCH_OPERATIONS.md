# RESTNEW 025 - Multi-Branch Operations & Central Kitchen

Adds enterprise multi-branch restaurant operation foundations inside RestaurantNew.

## Included
- Branch operation profile
- Central kitchen and commissary flags
- Branch recipe policy controls
- Branch transfer header and line records
- Transfer approval, dispatch, and receiving status flow
- Branch comparison KPI snapshot table
- Multi-branch dashboard
- Transfer list page
- Branch comparison report
- SQL create and permission scripts

## Main route
`/restaurant-new/multi-branch`

## Notes
This stage remains standalone under the RestaurantNew namespace and does not place restaurant logic in shared application files.
