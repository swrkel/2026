# Report Catalog

Restaurant-New includes these separately permissioned report tabs:

1. Sales
2. Item Sales
3. Kitchen Performance
4. Cashier
5. Takeaway and Collection
6. Hourly Sales
7. Waiter Performance
8. Discounts
9. Voids and Adjustments
10. Stock Usage
11. Purchases
12. Wastage
13. Menu Profitability

Every report is business-scoped and location-filtered through the current user's permitted locations. Date inputs are validated and CSV export reuses the same scoped query as the displayed report.
