MA-002 - CORE ReportController : RETIREMENT MAP
=====================================================================
Written against build 9800. No code was changed to produce this.

WHY THIS EXISTS
  app/Http/Controllers/ReportController.php is 20,102 lines - the largest
  file in the system. I was about to split it into readable pieces when
  you said reporting is moving to a separate module, with each module
  carrying its own reports.

  Splitting a file that is being retired is wasted effort. So instead,
  this measures what stands between today and switching it off.


=====================================================================

=====================================================================
  route names                : 14
  route name collisions      : 0

  references to core ReportController : 0
  references to core TransactionUtil  : 0

  It stands on its own. Nothing about it needs fixing before it takes
  over, and it shares no data model with core's reporting.

  retired anyway - so the deletion would be thrown away with the file.
  They are listed here so the eventual retirement does not spend time
  migrating reports nobody can reach.


=====================================================================
SUGGESTED RETIREMENT ORDER
=====================================================================
  1. Decide which of the 78 routed reports the new module will carry.
     54 of 128 methods are not routed at all, and 20 of those are dead,
     so the real scope is 78 reports, not 128.

  2. Migrate the module-owned ones first. AutoRepairServices, Petro,
     Stocktaking, HR, PriceChanges, Manufacturing, Property, MPCS,
     BankingInsurance and Pawning between them hold 73 references. You
     said each module will carry its own reports - these are exactly
     those, and each module can move independently without waiting for
     the others.

  3. Then the 27 references in core views.

  4. The two route files last. They are the bulk of the count but the
     simplest change once nothing else points at the controller.

  5. Only then delete the file.

  BEFORE STEP 5, instrument it the way I did /finance/accounts - one log
  line per call - and leave it a few weeks. 20,102 lines is too much to
  delete on static analysis alone, and a report someone runs once a
  quarter will not show up in any code search. Say the word and I will
  add that.
