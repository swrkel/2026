# MYHEALTH_022 Nursing Module

Added standalone nursing workflow inside My Health.

Included:
- Nursing dashboard
- Nursing station / patient queue
- Vital signs with BMI calculation and critical/warning flags
- Nursing notes
- Medication Administration Record (MAR)
- Care plans
- Shift handovers
- Nursing routes, controllers, entities, service, views, migration, permissions and sidebar entries

Run:

```bash
php artisan optimize:clear
php artisan migrate
```
