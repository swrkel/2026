# MYHEALTH_021 - Hospital Information System

Adds the first hospital-grade workflow inside the standalone My Health module.

Included:
- Hospital/HIS dashboard
- Reception dashboard
- Patient search from reception
- Appointment booking
- Token and queue number generation
- Waiting queue
- Doctor session schedules
- Consultation rooms and hospital departments database layer

Commands after replacement:

```bash
php artisan optimize:clear
php artisan migrate
```
