# BS011 Beauty Saloons Branch & Resource Management

This parcel adds standalone Beauty Saloons branch and resource management files under `Modules/BeautySaloons`.

## Included
- Branch master
- Chair master
- Resource master
- Branch settings
- Branch holidays
- Branch/resource controllers
- Branch/resource services
- Routes
- Views
- Migrations
- Reports
- Permissions
- JS/CSS
- Utility for branch/resource numbering

## Important
Install this as one consolidated parcel after BS010. Do not mix with old BS011 patches.
