FinanceReports Enterprise v2.0 - Financial Intelligence Platform

This release continues the standalone Finance Reports module without replacing or modifying the existing Finance module.

Added in v2.0:
- Financial Intelligence - New
- CFO Dashboard - New
- Financial Health Score - New
- Scenario Analysis - New
- Board Pack - New
- FinancialIntelligenceService
- Grouped portal menu update under Finance Reports
- Additional v2.0 permissions

Design rules preserved:
- Read-only reporting layer
- Branch/location wise reporting
- Consolidated reporting
- Existing Finance module untouched
- Own routes/controllers/services/views/config/menu/permissions under Modules/FinanceReports

Suggested installation:
1. Backup current code.
2. Replace/add the FinanceReports folder under Modules.
3. Clear application cache if required.
4. Verify sidebar shows Finance Reports and the v2.0 Intelligence group.
5. Test branch and consolidated filters using Trial Balance, P&L, Financial Intelligence and Board Pack.
