FinanceReports Enterprise RC-2 Final
===================================

Purpose
-------
This package finalizes the standalone Finance Reports module as a read-only enterprise reporting layer.
It is designed to sit beside the existing Finance module without replacing operational accounting pages.

Major additions in RC-2
-----------------------
1. Standalone Audit Center
   - Confirms module isolation under Modules/FinanceReports
   - Confirms read-only reporting behavior
   - Confirms branch/location wise and consolidated reporting framework

2. Export Center
   - Shared export framework for PDF / Excel / CSV / Print payloads
   - Keeps export generation inside the Finance Reports module

3. Print Layout Center
   - Standard report print header framework
   - Company / branch / period / generated by / generated on metadata

4. Drilldown Center
   - Read-only drill-down path framework
   - Statement -> Group -> Ledger -> Voucher -> Transaction

5. Dedicated RC-2 services
   - Services/Export/FinanceReportExportService.php
   - Services/Print/FinanceReportPrintService.php
   - Services/Security/FinanceReportsPermissionService.php
   - Services/DrillDown/FinanceReportDrillDownService.php
   - Services/Audit/FinanceReportsStandaloneAuditService.php

6. Dedicated configuration
   - Config/reports.php
   - Config/menu.php

7. Permission seeder
   - Database/Seeders/FinanceReportsPermissionSeeder.php

Important
---------
- Existing Finance module files are not replaced.
- Existing Finance controllers, routes, views and JavaScript are not replaced.
- Finance Reports is read-only and should not post, edit or delete accounting transactions.
- All new additions remain under Modules/FinanceReports.

Suggested sidebar title

Finance Reports

Installation
------------
Copy the FinanceReports folder to Modules/FinanceReports.
Do not overwrite the original Finance module.
Clear route/config/view cache after copying.
