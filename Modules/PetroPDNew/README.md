# PetroPDNew Module

Standalone Petro PD-New Laravel module paired exclusively with Pumper Dashboard-New.

- Module route prefix: `petro-pd-new`
- Permission prefix: `petro_pd_new.`
- Database prefix: `pdnew_`
- Source module: `PumperDashboardNew`
- Source prefix: `pone_`
- Fresh/upgrade tenant SQL: `SQL/00_MASTER_INSTALL_PETRO_PD_NEW.sql`
- Tenant verification SQL: `SQL/06_VERIFY_INSTALLATION.sql`

The module has no runtime dependency on legacy Petro PD or legacy Pumper Dashboard module code. Refer to the package-root architecture and deployment documents before installation.
