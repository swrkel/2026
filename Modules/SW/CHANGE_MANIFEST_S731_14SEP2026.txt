REQUIREMENTS IMPLEMENTED

1) Settlement -> Payment tab isolation

2) Save Settlement button only when Balance = 0.00
   - Save Settlement submit button now starts hidden/disabled.
   - It is shown/enabled only when at least one SW shift is selected AND abs(Total Amount - Total Paid) < 0.005.
   - Changing/selecting a shift hides the button until the payment summary/totals are recalculated.

   - SettlementSaveService has a server-side balance guard, so cached pages/direct submissions cannot finalize a non-zero settlement.

3) Meter Sales / Other Sales - Amount After Discount
   - Added a dedicated "Amount After Discount" heading for Meter Sales and Other Sales only.
   - Credit Sales wording is not changed.
   - Corrected FIXED discount semantics: the entered fixed value is one fixed line discount, NOT quantity x discount.
     Example from the issue image: 100 x 368.75 = 36,875.00; fixed discount 875.00 => Amount After Discount 36,000.00.
   - Percentage discount remains percentage of Amount Before Discount.
   - Old browser drafts are recalculated on restore using the corrected formula.
   - Server re-calculates Meter/Other Sale amounts before saving, protecting against stale browser cache using the old formula.
