# DIGITALWALLET_001 – Foundation & Ledger

DigitalWallet is a new standalone enterprise wallet platform. It does not depend on the legacy Wallet module, CommunicationHub internals, MyHealth, Finance, or other business modules.

## Included

- Dashboard
- Wallet register
- Ledger entries
- Transaction register
- Top-up and charge service foundation
- Spending rules foundation
- Settings
- Reports foundation
- Multi-currency-ready schema
- Multi-business / branch fields

## Architecture

The module owns its controllers, services, entities, routes, views, config, permissions, reports, migrations, and documentation.

CommunicationHub integration will be added later through a defined interface only.
