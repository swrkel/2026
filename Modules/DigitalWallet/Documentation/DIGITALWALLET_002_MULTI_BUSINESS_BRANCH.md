# DIGITALWALLET_002 - Multi-Business & Multi-Branch Wallets

This phase adds enterprise wallet hierarchy support while keeping the module 100% standalone.

## Included
- Business, branch, department, user and shared wallet levels.
- Parent-child wallet hierarchy.
- Configurable wallet types such as SMS, Email, WhatsApp, Push, API and AI credits.
- Daily and monthly spending limits.
- Credit limits and wallet lock controls.
- Wallet transfers with balanced ledger entries.
- Approval request foundation.
- Hierarchy dashboard and transfer register.

## Independence
This module does not depend on the legacy Wallet module, CommunicationHub internals, My Health, or any ERP business module. It uses only Laravel and the shared multi-tenant infrastructure.
