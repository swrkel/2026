# STN_044 Enterprise Operations Analytics

Adds enterprise analytics for StockTransfer-New without duplicating product, finance, POS, or inventory modules.

## Includes
- Enterprise Operations Analytics dashboard
- Transfer efficiency KPIs
- Warehouse productivity summary
- Vehicle utilization summary
- Product movement analytics
- Business/location/store benchmarking
- Bottleneck detection register
- Snapshot saving for month-end review
- CSV export

## SQL order
1. STN_044_CREATE_TABLES.sql
2. STN_044_ALTER_TABLES.sql
3. STN_044_INSERT_PERMISSIONS.sql

Run SQL in each tenant database where StockTransfer-New is enabled.
