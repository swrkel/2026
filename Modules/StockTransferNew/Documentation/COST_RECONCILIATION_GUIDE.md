# StockTransferNew STN_025 - Cost Reconciliation Guide

This package adds a standalone cost reconciliation page for StockTransferNew.

## Purpose
- Compare transfer dispatch cost against received cost.
- Identify value variances caused by shortage/excess/damage during receipt.
- Give admins a CSV export for accountant review.

## Important
- Product master remains in the existing standalone Products module.
- This package does not duplicate product creation or product management.
- Run the tenant SQL after earlier StockTransferNew SQL files.
