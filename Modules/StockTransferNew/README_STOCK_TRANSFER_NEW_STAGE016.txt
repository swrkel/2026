Stock Transfer-New Stage 016 Tester Support

This parcel is for QA/tester support after installing the production-ready module:
1. Guided test cases for request, approval, dispatch, receive, variance, return and reports.
2. Troubleshooting page for common issues found during testing.
3. Safe cleanup preview service for identifying test transfers before a manual/admin cleanup.
4. SQL for test checklist, issue notes and cleanup log tables.

Important:
- Cleanup tools are conservative. They do not remove product master data.
- Products remain in the existing standalone Products module.
- SQL must be run in each tenant DB where StockTransferNew is enabled.
