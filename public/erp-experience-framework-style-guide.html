ERP Experience Framework (EXF) Style Guide

Component 001: Tabs

Tabs use compact adaptive widths, automatic colour cycling, and white active tab with black text.

Design tokens: --exf-tab-height, --exf-tab-padding-x, --exf-tab-font-size, --exf-tab-icon-size, --exf-tab-icon-gap.

Safe Overrides

Use erp-tabs-normal for bigger tabs, erp-tabs-ultra-compact for tighter pages, or no-exf-tabs to opt out for special pages.

Framework Rule

Do not hard-code tab colours or sizes inside module pages. Use the framework tokens or override classes.
